# Forblune OS

> **Personal Operating System for AI-Assisted Development**  
> **AI와 함께 성장하는 개인 운영체제**

---

# 🚀 What is Forblune OS? (Forblune OS란?)

Forblune OS is a personal operating system designed to continuously improve the way I learn, build, and manage projects with AI.

Forblune OS는 AI와 함께 학습하고, 개발하고, 프로젝트를 관리하는 방식을 지속적으로 발전시키기 위한 개인 운영체제입니다.

Instead of starting every project from scratch,
the system itself evolves through every project.

프로젝트를 새로 시작하는 것이 아니라,
프로젝트를 할수록 **운영체제 자체가 성장하는 것**을 목표로 합니다.

Forblune OS는 경험을 **지식(Knowledge)**, **기술(Skill)**, **워크플로우(Workflow)**, **시스템(System)** 으로 축적하기 위한 개인 운영체제입니다.


---

# 🎯 Vision (비전)

> **Every project should improve not only the product, but also the system used to build it.**

모든 프로젝트는 제품뿐만 아니라,
그 제품을 만드는 시스템도 함께 발전시켜야 합니다.

# 🧠 Core Philosophy (핵심 철학)

Experience should never disappear.

Every project should leave something behind.

경험은 프로젝트와 함께 사라져서는 안 됩니다.

모든 프로젝트는 최소 하나 이상의 자산을 남겨야 합니다.

- Knowledge (지식)
- Skill (기술)
- Template (템플릿)
- Checklist (체크리스트)
- Workflow (워크플로우)
- Prompt (프롬프트)
- Automation (자동화)
- Review (회고)

### Goal

Transform experience into reusable systems.

Build systems that continuously improve themselves.

경험을 재사용 가능한 시스템으로 만든다.

지속적으로 스스로 발전하는 시스템을 만든다.

# 📖 Principles (원칙)

- Think in systems. (시스템 단위로 사고한다.)
- Build small first. (작게 만들고 빠르게 검증한다.)
- Reuse before create. (새로 만들기 전에 재사용을 생각한다.)
- Document before forgetting. (잊기 전에 기록한다.)
- Improve after every project. (모든 프로젝트 후에는 시스템을 개선한다.)
- AI assists, humans decide. (AI는 돕고, 최종 결정은 사람이 한다.)

## Repository Rules (저장소 규칙)

1. Every project should improve the system.
2. Every experience should become knowledge.
3. Every repeated task should become automation.
4. Every useful solution should become a skill.
5. Documentation is part of development.

---

1. 모든 프로젝트는 시스템을 개선해야 한다.
2. 모든 경험은 지식이 되어야 한다.
3. 반복 작업은 자동화해야 한다.
4. 유용한 해결 방법은 Skill이 되어야 한다.
5. 문서화도 개발의 일부다.
